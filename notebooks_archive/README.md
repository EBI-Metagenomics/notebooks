# Archived notebooks

These notebooks preserve examples from the retired MGnify notebook environment.
They are **not maintained or runnable**: they use old APIs and packages, and their
supporting code, datasets and execution environment have been removed. Original
notebook contents and outputs are preserved. They are not rendered or published.

Use the current [browser examples](https://docs.mgnify.org/src/examples/) instead.

The paginated CSV-download notebook and notebook index were replaced by the new
pages and removed. Partially migrated notebooks remain here, including AtlantECO
(its annotation/BGC sections), Python study loading (its instrument plot), and R
analysis metadata (its phyloseq section).
